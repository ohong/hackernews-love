# Cover artwork

The Dropbox cover uses `public/art/cloud-archive.webp`, a 640 × 640 transparent WebP. It was generated with the built-in image generation tool and resized with Sharp, preserving its alpha channel. Other covers use native SVG ornaments.

## Final generation prompt

```text
Use case: illustration-story
Asset type: engraved artwork for the cover of a digital clothbound book about Dropbox, in an editorial library called Hacker News Love.
Primary request: a beautifully detailed vintage copperplate engraving of a small open cardboard archive box, with a single elegant cloud emerging above it and three loose paper sheets gently suspended between the box and cloud. A poetic image of files freed from their box.
Style/medium: intricate 19th-century scientific book engraving, fine cream-white etched lines and crosshatching, restrained and elegant, no cartoon outlines, no 3D rendering.
Composition: centered complete isolated vignette, square canvas, ample transparent margins. The box and cloud together form a compact vertical composition.
Color: monochrome warm ivory ink (#f3ead3). This artwork will be placed on a deep midnight blue book cover, so the fine lines must remain light.
Constraints: genuinely transparent background, no colored backdrop, no text, no letters, no logos, no border, no watermark.
```
